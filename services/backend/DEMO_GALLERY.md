# Demo portfolio photographs

Seeded into the **dev database only** on 2026-09-17 so the customer-side
portfolio mosaic has work to show. Every picture is CC0 1.0 (public domain
dedication) sourced through the Openverse API, stored as a data URL in
`portfolio.GalleryImage.image` like every other picture in this project.

Each salon's own logo row was kept but moved to `sort_order = 9` so a
photograph, not the logo, leads the mosaic.

Remove it all with:

    uv run python manage.py shell < undo_demo_gallery.py
